# 💰 Daily Money

매일 쓴 돈을 **3번 탭, 5초 안에** 기록하고, 월 목표 지출을 지키도록 도와주는 PWA 가계부입니다.
서버 없이 동작하며 데이터는 이 기기의 브라우저(localStorage)에만 저장됩니다.

## 주요 기능 (v1)
- **오늘 쓸 수 있는 돈**: (월 목표 − 어제까지 쓴 돈) ÷ 남은 일수 − 오늘 쓴 돈. 아끼면 다음 날 늘어나요.
- **빠른 입력**: 위쪽 숫자 키패드(`00`, `+1천`, `+5천`, `+1만`)로 금액 입력 → 아래쪽 카테고리를 누르면 바로 저장
- **원탭 칩**: ⭐ 즐겨찾기 + 최근 자주 쓴 조합 자동 추천(지금 시간대 우선)
- **되돌리기 토스트**: 저장·수정·삭제 후 4초간 되돌리기
- **한 화면 고정**: 오늘 탭은 스크롤 없이 요약·입력·키패드가 한 화면에 들어가요
- **수정/삭제**: 일별 탭에서 항목을 누르면 수정, 왼쪽으로 밀면 삭제
- **페이스 경고**: "이 속도면 월말에 ₩xx 초과 예상"
- **무지출 데이 & 스트릭 🔥**: 기록을 시작한 뒤 지난 날짜에 지출이 하나도 없으면 자동으로 무지출(보라색 🙌)
- **일별 탭**: 달력에 날짜별 지출을 만원 단위 숫자로 크게 표시(하루 예산 이하 초록, 초과 빨강, 무지출 보라 🙌), 월 이동, 월 통계(총 지출·하루 평균은 만원 단위, 무지출), 날짜를 누르면 그날 내역과 "이 날 지출 추가"
- **월별 탭**: 1~12월 월별 총 지출(만원 단위)(월 목표 이하 초록, 초과 빨강), 연 통계(올해 지출·월 평균·목표 달성 개월), 월을 누르면 유형별 막대 그래프와 "일별로 보기"
- **백업**: 데이터 보호 요청(저장 공간이 부족해도 지우지 않도록), 백업 파일을 카톡·메일로 보내기, 마지막 백업 후 30일이 지나면 알림(나중에 → 3일 뒤 다시)
- **설정**: 월 목표, 한 달 시작일(월급날), 카테고리 편집/순서, 즐겨찾기 관리, JSON 백업/복원, CSV 내보내기
- **화면 모드**: 설정에서 자동(시스템 따라감) / 라이트 / 다크 선택
- **PWA**: 홈 화면 설치, 오프라인 동작, 앱 아이콘 길게 눌러 "지출 추가" 바로가기, 다크 모드

## 실행
빌드가 필요 없습니다. 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 배포 (GitHub Pages)
저장소 Settings → Pages → Branch를 배포할 브랜치와 `/ (root)`로 지정하면
`https://<user>.github.io/daily_money/`에서 사용할 수 있습니다. 모든 경로가 상대 경로라 하위 경로에서도 동작합니다.

> 파일을 수정한 뒤에는 `sw.js`의 `CACHE` 버전을 올려야 설치된 앱이 새 버전을 받습니다.

## 구조
```
index.html        앱 셸
manifest.json     PWA 매니페스트 (아이콘, 바로가기)
sw.js             서비스워커 (오프라인 캐시)
css/style.css     스타일 (라이트/다크)
js/app.js         화면 렌더링, 입력/이벤트 처리
js/store.js       저장소 (localStorage), 백업 데이터 검증
js/budget.js      예산 기간, 일일 가용액, 페이스, 스트릭 계산
js/suggest.js     빠른 입력 칩 추천
icons/            앱 아이콘
```
